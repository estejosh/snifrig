Install

  1. Download snifrig-setup.exe and run it.
  2. The beta is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click More info, then Run anyway.
  3. snifrig starts at login with a tray icon. Open the window from the tray or the Start menu.
  4. For snifrig fix: open the app, go to Settings, copy your PC ID, and email it to us for a beta key.

Questions

Is it safe to run a beta?

snifrig never ends an app on its own. It only lowers the priority of busy background apps, and every change has an undo. Ending or restarting anything asks you first. Uninstall any time from Settings > Apps.

Does it send my data anywhere?

No. Everything stays on your PC. There is no account and no phone-home. Alerts go out only if you set up a webhook yourself.

Why is SmartScreen warning me?

The installer is not signed with a paid code-signing certificate yet. The source is public on GitHub, so you can read or build it yourself.

Something went wrong. What now?

Email helpmeagent@agentmail.to with what happened. A crash leaves crash.log in %LOCALAPPDATA%\snifrig; attach it if you can.
