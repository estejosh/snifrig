# snifrig-fix pricing

`snifrig-fix` is the paid Component of snifrig. It is licensed under UFL 3.7
(SPDX: `LicenseRef-UFL-3.7-U.P-snifrig-fix`). The monitor is free for everyone,
companies included. See [LICENSE](LICENSE).

## Published Price

Per Computer per year (UFL 3.7, Section 8):

| Computers | Price per Computer / year |
|---|---|
| 1 - 10 | $30 |
| 11 - 50 | $24 |
| 51 - 250 | $18 |
| 251+ | $12 |

Example: 20 Computers is 20 x $24 = $480 per year.

Enterprise or contract terms: contact the author at hello@fungibility.group.

## What you get

- An offline license key for `snifrig-fix`, signed and valid for 30 days.
- A key for each 30-day period while the paid period lasts. Keys are re-issued
  during the paid period.
- Optional binding of the key to one machine. `snifrig-fix machine-id` prints
  the machine hash.

## How to buy

1. Email hello@fungibility.group with the number of Computers.
2. A key is emailed for each 30-day period while you are paid.
3. Install the key: `snifrig-fix license install PATH`.
4. Accept the Component: `snifrig-fix license accept`.

## No trial

There is no trial and no free dry-run. `snifrig-fix` never runs without a valid
key, home users included. The monitor needs no key.

## How the key is checked

The key is checked entirely on your computer. There is no network call. A clock
set backwards is refused. This keeps honest users honest. It is not uncrackable.
